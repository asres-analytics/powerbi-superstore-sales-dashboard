# Global Superstore Dataset

## Source

Kaggle

https://www.kaggle.com/datasets/aditisaxena20/superstore-sales-dataset

---

## Description

The Global Superstore dataset contains transactional sales data from a global retail business.

The dataset includes:

- Orders
- Customers
- Products
- Categories
- Sub-Categories
- Regions
- Markets
- Shipping Information
- Revenue
- Profit
- Discounts
- Quantities

---

## Key Fields

### Sales Information

- Order ID
- Order Date
- Ship Date
- Sales
- Quantity
- Discount
- Profit
- Shipping Cost

### Customer Information

- Customer Name
- Segment

### Product Information

- Product Name
- Category
- Sub-Category

### Geographic Information

- Country
- State
- Region
- Market

### Shipping Information

- Ship Mode
- Order Priority

---

## Data Model Used

The Power BI solution is built using a Star Schema.

### Fact Table

- FactSales

### Dimension Tables

- DimDate
- DimCustomer
- DimProduct
- DimGeography
- DimShipping

---

## Purpose

The dataset is used to analyze:

- Revenue Performance
- Profitability
- Product Performance
- Geographic Performance
- Customer Behavior
- Shipping Efficiency
